# MoonResilience

MoonResilience is a pure MoonBit resilience toolkit for service calls, background jobs, message consumers, and infrastructure tools.

The project provides reusable retry, circuit breaker, rate limiter, bulkhead, policy composition, telemetry, configuration, and deterministic simulation capabilities. It does not depend on a network framework or a wall clock, which keeps the core package portable and testable.

## Status

Version `0.2.0` is under active development for the 2026 MoonBit open-source ecosystem competition.
